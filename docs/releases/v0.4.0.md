# CRDD IR v0.4.0

v0.4.0 introduces portable typed contracts for collection referential
integrity, byte-exact unknown data, and inactive unknown-extension
immutability.

## Added

- `IR-COLLECTION-001`: unique IDs, typed references, parent membership, and
  typed relation endpoints
- array and string-keyed map collections in both input and state
- compile-time ID and reference-key type compatibility diagnostics
- `IR-OPAQUE-001`: canonical Base64, byte-exact round trip, SHA-256, and active
  state
- `IR-IMMUTABLE-001`: deterministic rejection of inactive unknown-extension
  edits
- Unreal C++ and Unity C# generation from the same normalized portable rules
- generated negative conformance cases and portable-rule mutation analysis
- Target-emitted semantic records used to derive `portableRulesSha256`
- generated Unreal Automation and Unity NUnit portable conformance suites
- fail-closed immutability and value-copy unknown-data projection

## Compatibility

The Source Contract and Core IR changes are additive. v0.3.1 contracts compile
unchanged. Adopters using the new rules must regenerate target code,
conformance bundles, parity evidence, and batch manifests.
