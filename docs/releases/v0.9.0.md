# CRDD IR v0.9.0

v0.9.0 adds portable collection quantifiers and deterministic output/event
projection for Unreal and Unity.

## Added

- `all` and `any` boolean expressions for array and map values, including
  mathematical empty-collection semantics.
- scoped `item.*` access with comparisons to `input.*`, `state.*`, and constants.
- post-effect `returns` mappings validated against the declared output schema.
- event `when` and payload `value` mappings with access to immutable
  `previous.*` state for transition-edge detection.
- output and event fields in generated Unreal and Unity operation results and
  product bridge result DTOs.
- cross-runtime fixtures for normal false, rising-edge emission, repeat-call
  suppression, and failure rollback.

## Compatibility

Existing v0.8 contracts remain valid. Existing declarative `output` and `emits`
metadata continue to compile; executable projection is enabled by adding
`returns` and event `value` mappings.

Engine-specific presentation sequencing remains an adapter responsibility.
