# CRDD IR v0.7.0

v0.7.0 adds deterministic conditional state transitions and a reviewed way to
adopt intentional project configuration changes.

## Added

- `effect.when` for conditional assign, increment, append, remove, and update
- optional effect `traces` included only when that branch is applied
- conditional Requires through `requires[].when`
- deterministic conformance cases for every declared enum branch
- mutation detection for removed and inverted effect/Requires branches
- identical branch, error, trace, and rollback semantics in Simulator, Unreal,
  and Unity
- `project adopt-config <config>` with schema/Doctor safety validation
- `--dry-run` and `--format json` audit output containing old and new SHA-256
- atomic update of only the config entry in `.crdd-ir.install.json`

## Compatibility

Existing contracts do not need migration because `when` and branch traces are
optional. Generated target files and conformance bundles must be regenerated.
The installation manifest remains protocol v0.2; its published JSON Schema is
corrected to match the installer and Doctor protocol already used since v0.4.

## Configuration adoption

After reviewing an intentional config change:

```powershell
node tools/CRDD-IR/src/cli.ts project adopt-config crdd-ir.config.json --dry-run
node tools/CRDD-IR/src/cli.ts project adopt-config crdd-ir.config.json
```

CI should continue to run `project doctor`; it never adopts changes
automatically.
