# CRDD IR v0.2.0

v0.2.0 expands CRDD IR from an Unreal-focused compiler into a multi-target compiler
toolchain.

## Highlights

- Unity C# contract, product bridge, and NUnit conformance generation
- Unity 6, .NET Standard 2.1, Mono, and IL2CPP target profiles
- Target Registry shared by single-operation and batch generation
- Generic `generate <target>` and `batch <target>` command routing
- Machine-readable `target list` and `target describe <target>` discovery
- Backward-compatible `unreal generate` and `unity generate` aliases
- Extensible batch manifests for registered target IDs

The CRDD source and IR protocol identifiers remain at their existing compatible versions.
The product and generated-code version is `0.2.0`.
