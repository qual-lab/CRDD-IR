# CRDD IR v0.2.0

v0.2.0は、Unreal中心だったCRDD IRをUnreal／Unity対応のmulti-target compiler
toolchainへ拡張するリリースです。

## Highlights

- Unity C# Contract、製品Bridge、NUnit Conformance Test生成
- Unity 6、.NET Standard 2.1、Mono／IL2CPP Target Profile
- 単一Operationとbatch生成で共通のTarget Registry
- 汎用`generate <target>`／`batch <target>`コマンド
- 機械可読な`target list`／`target describe <target>`
- `IR-TARGET-001`: Unreal C++／Unity C#の独立target生成Evidence
- `IR-PARITY-001`: 両targetの決定的な静的意味同値性検証
- Unity EditMode TestとWindows x64 IL2CPP Buildを行うFixture

## Compatibility

- Product／生成コードversion: `0.2.0`
- Node.js: `22.18.0`以降
- Unreal検証環境: Unreal Engine 5.8、Win64
- Unity検証環境: Unity `6000.5.5f1`、Windows x64、IL2CPP
- CRDD Source Contract／Internal IR／既存Evidenceのprotocol IDは互換性維持のため
  `v0.1`のままです
- `unreal generate`と`unity generate`は互換aliasとして継続します

## Generate

Unreal:

```powershell
node tools/CRDD-IR/src/cli.ts generate unreal contracts/operation.md `
  --profile Config/CRDD/ue-5.8-editor.json `
  --out-dir Source/MyGame/Generated
```

Unity:

```powershell
node tools/CRDD-IR/src/cli.ts generate unity contracts/operation.md `
  --profile Config/CRDD/unity-6-il2cpp.json `
  --out-dir .crdd-ir/unity-generated
```

複数Operation:

```powershell
node tools/CRDD-IR/src/cli.ts batch unity `
  contracts/create-operation.md `
  contracts/update-operation.md `
  --profile Config/CRDD/unity-6-il2cpp.json `
  --out-dir .crdd-ir/unity-generated `
  --flat
```

## Target parity

```powershell
node tools/CRDD-IR/src/cli.ts target parity contracts/operation.md `
  --unreal-profile Config/CRDD/ue-5.8-editor.json `
  --unity-profile Config/CRDD/unity-6-il2cpp.json `
  --out evidence/crdd-ir/target-parity.json
```

Parity gateは同一IR、同一Conformance semantics、target独立性、数値型のbit幅、
JSON表現、丸め、overflow方針を比較します。不一致の場合は終了コード1です。
Engineでの実行結果そのものは静的Parityとは分けて`verify:unreal`／
`verify:unity`で検証します。

## Verification


## Upgrade from v0.1.2

Submodule利用側:

```powershell
git -C tools/CRDD-IR fetch origin --tags
git -C tools/CRDD-IR checkout v0.2.0
npm.cmd ci --prefix tools/CRDD-IR

.\tools\CRDD-IR\scripts\repair-project.ps1 -ProjectRoot .
.\tools\crdd-ir.ps1 doctor
.\tools\crdd-ir.ps1 verify
```

Unityを利用する場合は、Unity Target Profile、Runtime asmdef、Test asmdefを追加し、
生成されたRuntime/Testファイルを分離配置してください。既存Unreal適用先は
従来コマンドを継続利用できます。

## Known boundaries

- `install-project.ps1`／`repair-project.ps1`のscaffold対象はUnrealです
- Unity製品Projectへのasmdef配置と生成ファイル振り分けは適用先が所有します
- `target parity`は決定的な静的gateです。Engine実行Evidenceの統合reportでは
  ありません
- UnityのGameObject／Addressables／シーン実装、UnrealのWorld Projectionなど、
  製品固有ProjectionはCRDD IRへ取り込みません
- macOS、Linux、mobile、console向けUnity Player Buildは未検証です
