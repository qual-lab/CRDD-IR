# CRDD IR v0.8.0

v0.8.0 adds reviewable, deterministic conformance baselines and branch seeds
for constraints that require several input or state fields to change together.

## Added

- optional `operation.conformance.baseline` values in Source Contracts
- condition-owned `operation.conformance.seeds`
- multiple independently identified seeds for the same normalized condition
- Requires-filtered `pairwise` and `exhaustive` combination coverage
- typed expression normalization for seed conditions
- schema, enum, range, unknown-field, duplicate-owner, and Requires validation
- fail-closed diagnostics that identify an invalid seed and conflicting Requires
- shared Unreal and Unity branch fixtures through the existing conformance bundle
- seed ownership in the Internal IR digest and target parity evidence

## Compatibility

The feature is optional. Existing v0.7.0 contracts require no source migration.
After adding a conformance plan, regenerate Internal IR, conformance bundles,
target code, regression manifests, and target parity evidence.

No product-specific decision logic is introduced into target adapters.
