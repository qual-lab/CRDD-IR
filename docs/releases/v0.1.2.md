# CRDD IR v0.1.2

v0.1.2は、Unreal製品への組み込み境界、複数Operation回帰、検証ロックEvidence、
Windows checkout再現性を強化するリリースです。

## Highlights

- OperationごとのUnreal Product Bridge DTO／Adapter scaffoldを生成
- Contract成功時のみSnapshotをcommitし、失敗時は元Snapshotを保持
- 複数Operationを束ねる製品回帰manifestとConformance Bundleを生成
- verify lockのwaiting／acquired／timeout／releasedイベントをJSONLで記録
- lock待機時間、取得状態、abandoned lock回収をBuild Evidenceへ収録
- `verify:unreal`全体を直列化し、並行UAT実行の競合を防止
- 数値Projectionのchecked arithmeticと生成Numeric Boundary Automationを提供
- WindowsのCRLF/LF差をownership SHA-256で正規化
- 標準生成物を`.gitattributes`でLF固定

## Unreal integration

`unreal generate`と`batch unreal`は、各Operationについて次を追加生成します。

- `<Operation>.bridge.generated.h`
- `<Operation>.bridge.generated.cpp`
- `<Operation>.bridge.generated.spec.cpp`

製品側は生成された`ICrdd<Operation>ProductAdapter`を実装し、Request変換、
authoritative Snapshot取得、revision付き原子的commitを担当します。Actor、World、
Asset、表示Projectionは引き続き製品側の責務です。

## Upgrade

CRDD適用先でSubmoduleを更新し、管理ファイルを修復してから検証します。

```powershell
git -C tools/CRDD-IR fetch origin --tags
git -C tools/CRDD-IR checkout v0.1.2
npm.cmd ci --prefix tools/CRDD-IR

.\tools\CRDD-IR\scripts\repair-project.ps1 -ProjectRoot .
.\tools\crdd-ir.ps1 doctor
.\tools\crdd-ir.ps1 verify
```

生成SourceディレクトリにはBridge関連ファイルが追加されます。生成manifestで所有される
ため、手編集せず、製品実装は別ファイルのAdapterへ置いてください。

- Windows PowerShell
- Unreal Engine 5.8
